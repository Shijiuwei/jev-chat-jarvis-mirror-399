## 0. 装机
```
. H:\ai_tool\jev-android\env.ps1; Set-Location H:\ai_tool\jev-android
adb install -r app\build\outputs\apk\debug\app-debug.apk
adb shell appops set com.jev.probe SYSTEM_ALERT_WINDOW allow
```
然后**手机上把无障碍关掉再打开**（新增了截屏能力，HyperOS 不热更新 meta-data）。看 `adb logcat -s JEVASSIST` 有 `capture service connected` 和 `prefs migrated judgeKey.len=N`（N>0 = 旧密钥迁移成功）。

## 1. A：接口自定义
- 打开设置 → 三张接口卡渲染正常，判断卡里旧 OpenRouter 密钥还在。
- 「测试判断」「测试回复」各点一次，看耗时和结果；把回复接口切 DeepSeek 官方预设再切回 OpenRouter（预设要同时换地址和模型）。
- QQ 进一个对话，分析一次，确认主链路没坏。

## 2. D：知识库 / 上下文
- 设置 → 分析 → 点小字「自检」，应返回"通过"。
- 「知识库与联系人」建一条常驻笔记，写一个虚构事实（如"我下周三去成都"）；对某个联系人建档并填别名；开「记录聊天历史」。
- 对该联系人分析：面板出现「知识库 N 条 · 历史 M 条」，候选回复里能看到那个事实。
- 「清空知识库与历史」后计数归零。

## 3. B：OCR（最不确定，先探路）
- 任意 App 里长按悬浮球 → 「截屏识别一次」。看面板：出候选 = 截屏被放行；出「内部错误 / 系统拒绝」= HyperOS 拒绝无障碍服务截屏 → 按修订另起一个截屏专用服务（新任务）。
- 飞书进对话：正文应被 OCR 出来并分析；核对我/对方是否判反（已读容器判 me 是推断）。
- App 里观察 logcat 不应出现每秒一张截屏（签名去重）。
