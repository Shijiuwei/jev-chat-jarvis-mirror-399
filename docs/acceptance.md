```
python tools/jev/calibrate.py
```

- 标注集不少于 20 条中文对话片段

- `true_intent` / `she_needs` 命中率 ≥ 60%

1. 对方发来新消息后 **1.5 秒内**悬浮窗出现分析，候选回复不少于 3 条且已排序

3. 自己发的消息不触发；切换会话上下文重置；App 切后台悬浮窗隐藏
4. 密钥不出现在 logcat；断网时给可读错误不崩溃
